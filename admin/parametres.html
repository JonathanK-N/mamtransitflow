TransitFlow

Parametres

Votre entreprise, les applications actives et ce que voient vos chauffeurs.

Ce nom apparait dans l interface, dans les invitations envoyees aux chauffeurs (« Rejoignez votre entreprise sur TransitFlow ») et sur les bulletins de paie.

Activez les applications dont votre entreprise a besoin. Une application desactivee disparait des menus ; ses donnees sont conservees et reviennent si vous la reactivez.

Choisissez ce que vos chauffeurs peuvent faire dans leur espace. Ces choix s appliquent a tous les chauffeurs, immediatement, sur ordinateur comme sur telephone.

Calendrier et heures supplementaires

Loi sur les normes du travail : heures supplementaires au-dela de 40 h par semaine, majorees de 50 % (1,5). Indemnite de vacances : 4 % (6 % apres 3 ans de service) ; laissez 0 si elle est versee au moment des vacances.

Cotisations et retenues

Taux officiels 2026 pour le Quebec (RRQ, assurance-emploi, RQAP), a mettre a jour chaque 1er janvier. Les retenues d impot sont des taux forfaitaires que vous fixez : elles ne remplacent pas les tables de Revenu Quebec (TP-1015.F) et de l ARC (T4127). Faites valider vos parametres par votre comptable ; les remises et les releves 1 / T4 se font hors de TransitFlow.

Configuration (hebergement Railway, onglet Variables du service)
Option 1 — Resend (recommande, fonctionne meme quand le port SMTP est bloque) : TF_RESEND_CLE et TF_EMAIL_EXPEDITEUR (ex. Navettes Estrie <noreply@votre-domaine.ca>, domaine verifie chez Resend).
Option 2 — SMTP (Gmail Workspace, Microsoft 365, Brevo...) : TF_EMAIL_HOST, TF_EMAIL_PORT (587), TF_EMAIL_UTILISATEUR, TF_EMAIL_MOT_DE_PASSE, TF_EMAIL_EXPEDITEUR.
